# OKO — застосунок чату для Android

Брендована копія [Element X Android](https://github.com/element-hq/element-x-android) для командного чату програми ОКО
(Інтератлетика). Функції Element X не змінюються; змінено назву, значок, логотип і кольори.

Не пов'язано з Element офіційно. Код — AGPL-3.0, як і в Element X.

| Що | Де |
|---|---|
| Правила для виконавців | `docs/oko/PRAVYLA_VYKONAVTSIA.md` |
| Правила дизайну | `docs/oko/PRAVYLA_DYZAINU.md` |
| Завдання | `docs/oko/zavdannia/` |
| Протокол | `docs/oko/PROTOKOL.md` |
| Реєстр наших змін у коді Element | `OKO_PATCHES.md` (з'явиться після ЧА1) |
| Пакет бренду | `branding/oko/` |

Гілки: `oko/main` — наша версія (тег Element + наші зміни); `ai/*` — робота виконавців; `develop` та інші — гілки Element.
