# Розгортання вебпакета OKO

1. Завантажте артефакт `oko-web` зі збірки. Поруч із `oko-web-<тег>.tar.gz` є файл `SHA256SUMS`. У цій теці виконайте `sha256sum -c SHA256SUMS`. Розпакуйте архів у нову теку. Вебсервер має віддавати `index.html` із цієї теки. Тема, шрифти, шпалери й адреса Matrix `https://m.pro.ua` уже в пакеті.
2. Віддавайте Element і ОКО через HTTPS із різних піддоменів одного домену. Наприклад, `chat.example.org` і `oko.example.org`. На відповіді Element задайте `Content-Security-Policy: frame-ancestors https://oko.example.org`, підставивши точну адресу ОКО. Збережіть решту наявних директив CSP. Приберіть `X-Frame-Options` із відповідей Element, зокрема на проксі або CDN.
3. Для перевірки з ОКО повертайте також `Access-Control-Allow-Origin: https://oko.example.org` і `Access-Control-Expose-Headers: Content-Security-Policy, X-Frame-Options`. Вкажіть остаточну адресу Element із `/` у `OKO_MATRIX_WEB_URL`. Не використовуйте адресу з перенаправленням.
4. Відкрийте адресу чату. Перевірте вхід і знак OKO. У **Налаштування → Вигляд** вимкніть **Як у системі** й виберіть **OKO світла**. У кімнаті мають бути шпалери, у темі **OKO темна** — однотонний фон. Перевірте завантаження в панелі ОКО та відкриття з тієї самої робочої адреси через HTTPS.

Для оновлення звірте SHA-256 нового архіву, розпакуйте його в окрему теку й перемкніть корінь вебсайту на неї. Збережіть попередню теку для відкату. Якщо є CDN або кеш проксі, перевірте, що `index.html` і `config.json` уже віддаються з нової версії.

Пакет обмежує можливості в інтерфейсі Element. Правила реєстрації й зміни пароля визначає сервер Matrix.
