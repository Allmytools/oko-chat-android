- **28.11.2026 14:25 · Інтегратор — відповідь на «НЕЗАВЕРШЕНО: ЧА4» (різниця 9 338 / 4 626 пікселів).**
  Причина — інша версія растеризатора (у тебе rsvg-convert 2.63.4). Інтегратор перевірив у чистому середовищі:
  1. Генератор детермінований: `art.py desktop 3` / `art.py phone 4` (з `NOTAG=1 NOTB=1 BASE_D=310` / `BASE_P=215`)
     дають SVG, **побайтно ідентичні** `etalon/khaos_chystyi_desktop.svg` і `etalon/khaos_chystyi_phone.svg`.
  2. Растеризація в **Ubuntu 24.04.5** штатними пакетами дає **різницю 0** з обома еталонами (PNG відрізняються лише
     метаданими, пікселі однакові). Версії: `librsvg2-bin 2.58.0+dfsg-1ubuntu0.1`, `libcairo2 1.18.0-3build1`,
     `libpango-1.0-0 1.52.1+ds-1build1`, `fontconfig 2.15.0-1.1ubuntu2`, `libfreetype6 2.13.2+dfsg-1ubuntu0.2`,
     `libharfbuzz0b 8.3.0-2build2`, `fonts-liberation-sans-narrow 1:1.07.6-4` (шрифт
     `/usr/share/fonts/truetype/liberation/LiberationSansNarrow-Italic.ttf`). Python 3.13, numpy 2.5.3, Pillow 12.3.0.
  **Що робити:** перевірку відтворення запускати окремим кроком на `ubuntu-24.04` з `apt-get install librsvg2-bin
  fonts-liberation-sans-narrow` (без сторонніх збірок rsvg), вивести версії пакетів у журнал. Критерії:
  (а) SVG побайтно = еталонні SVG — **обов'язково**; (б) PNG попіксельно = еталон, різниця 0 — **обов'язково на цьому
  середовищі**. Якщо образ раннера оновив пакети і (б) не проходить, а (а) проходить — **не зупинятися**: записати версії
  й різницю в журнал і звіт, продовжити (у збірку однаково йдуть еталонні PNG без змін, їх SHA-256 перевірено).
  Зупинка лише якщо не збігся SHA-256 або SVG. **Продовжуй ЧА4 повністю (А–Г).**
- **28.11.2026 14:35 · Інтегратор — відповідь на «НЕЗАВЕРШЕНО: ЧА4 — настільний SVG не збігся побайтно».**
  Причина: `art.py` вбудовує контури виробів у SVG як PNG у base64, перекодовуючи їх Pillow (`im.save(..., optimize=True)`,
  рядок 45). Байти такого PNG залежать від версії Pillow і бібліотеки стиснення (zlib / zlib-ng), **пікселі — ні**. У
  контрольному середовищі інтегратора: Python 3.13.18, **Pillow 12.3.0 (pip-wheel), zlib-ng 1.3.1**, numpy 2.5.3 — там
  SVG побайтно збігаються. Побайтний збіг SVG — **занадто суворий критерій**, скасовую його.
  **Нові критерії перевірки відтворення (замість запису 14:25, пп. а–б):**
  (а) **SVG за змістом:** у згенерованому й еталонному SVG замінити кожне `data:image/png;base64,…` на хеш пікселів
  декодованого зображення (розмір + RGBA-байти) — після цього тексти SVG мають бути **ідентичні** (30 вбудованих
  зображень у настільному). Це обов'язково.
  (б) **PNG попіксельно:** растеризація на `ubuntu-24.04` зі штатними `librsvg2-bin` / `fonts-liberation-sans-narrow` —
  різниця з еталоном 0. Якщо не 0 при пройденому (а) — записати версії й різницю, **продовжити**.
  Необов'язково: ставити `pip install Pillow==12.3.0 numpy==2.5.3` на Python 3.13 — тоді SVG мають збігтися і побайтно
  (у журнал як інформацію). Зупинка — лише якщо не збігся SHA-256 архіву/еталонів або (а).
  **Продовжуй ЧА4 повністю (А–Г).**
