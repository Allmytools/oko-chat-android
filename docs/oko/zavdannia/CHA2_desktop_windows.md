# ЧА2 — OKO для Windows: збірка Element Desktop з дизайном OKO, перша тестова версія (26.11.2026)

**Виконавець:** Codex, «ОКО · Чат Android». Мітка відповіді: «[ОКО · Чат Android]».
**Репозиторій:** `Allmytools/oko-chat-android` (цей). Гілка роботи: `ai/oko-desktop` від `oko/main` → PR у `oko/main`, не зливати.
**Протокол:** `docs/oko/PROTOKOL.md`, розділ «ЧА2». **Правила:** `docs/oko/PRAVYLA_VYKONAVTSIA.md`.

## Мета
Інсталятор для Windows «OKO test»: Element Desktop з темою, сторінкою входу, домашньою сторінкою й значками OKO.
Функції Element не змінюються. Нові версії Element мають підхоплюватися зміною одного номера версії.

## Важливо про джерело
Окремого репозиторію `element-desktop` більше немає: з березня 2026 Element Desktop живе в монорепозиторії
`element-hq/element-web`, тека `apps/desktop`. **Форк не робимо.** Наш workflow щоразу бере готовий випущений тег
`element-web`, накладає наш бренд **файлами налаштувань під час збирання** і збирає інсталятор. Код Element не змінюється
взагалі — отже, оновлення = зміна номера тегу.

## Що вже є
- Пакет дизайну ДД1: `branding/oko/desktop/` — теми `theme_oko_light.json` / `theme_oko_dark.json`, `config_branding.json`,
  сторінка входу (`login/`), домашня сторінка (`home/`), значки (`icons/icon.png`, `icon.ico`, `favicon.ico`, `icon-192/512`),
  макети й `PEREVIRKA.md`.
- Рішення власника: свого шрифту немає; посилань унизу сторінки входу немає; зелені основні кнопки погоджено; текст правил
  на домашній сторінці й адреса ОКО — ще чернетка/заглушка (лишити як є, з позначкою).

## Етапи

### Е1. Каркас у нашому репозиторії (тека `desktop/`)
- `desktop/ELEMENT_WEB_TAG` — один рядок: тег останнього стабільного випуску `element-web`, що містить `apps/desktop`
  (визнач сам за релізами GitHub; запиши в звіт).
- `desktop/variant.test.json` — для змінної `VARIANT_PATH` (її читає `apps/desktop/electron-builder.ts`, файл Element не
  змінювати): `appId` `com.interatletika.oko.desktop.test`, `productName` «OKO test», `name` `oko-desktop-test`,
  опис українською, `protocols` — без протоколів Element. Підготуй і `variant.json` для робочої версії («OKO»,
  `com.interatletika.oko.desktop`), але не збирай її.
- `desktop/config/` — генератор `config.json` (скрипт, не ручне копіювання), що збирає:
  `brand: "OKO"`, `branding`, `embedded_pages.home_url`, обидві теми в `setting_defaults.custom_themes`,
  `default_theme` (світла OKO), `setting_defaults.layout: "bubble"`, вимкнену реєстрацію / гостьовий вхід, і
  **без** `update_base_url` (наша версія не має оновлюватися з серверів Element).
  Сервер Matrix **не прив'язувати** (домен ще не підтверджено): `default_server_config` — заглушка `https://matrix.example`
  з позначкою, вибір сервера дозволено. Одне місце для домену, як в Android.

### Е2. Workflow `oko-desktop-build` (GitHub Actions, `windows-latest`)
1. Checkout нашого репозиторію + checkout `element-hq/element-web` на тег з `ELEMENT_WEB_TAG` (у тимчасову теку).
2. В `apps/desktop`: встановити залежності (pnpm), завантажити **готовий** пакет Element Web того самого випуску з
   перевіркою підпису (`pnpm run fetch --importkey`, потім `pnpm run fetch --cfgdir <наш згенерований config>`; якщо в
   новій версії команди інші — за README `apps/desktop`).
3. Перед збиранням **скопіювати** наші значки поверх `apps/desktop/build/icon.ico` і `icon.png` у робочій копії
   (у нашому репозиторії файли Element не змінюються). Значок Mac не чіпаємо.
4. Зібрати інсталятор Windows з `VARIANT_PATH=desktop/variant.test.json`. Без підпису коду (сертифіката немає).
5. Артефакт `oko-desktop-windows-test`: інсталятор `.exe` (+ портативний варіант, якщо збирач його дає), контрольні суми.
- Тригери: push у `ai/oko-desktop`, PR у `oko/main`, ручний запуск. **Runner-и сервера ОКО не використовувати.**

### Е3. Перевірка
- Автоматично в workflow: інсталятор існує; у пакеті `config.json` містить наші теми, `brand`, `layout: bubble`, немає
  `update_base_url`; назва продукту «OKO test».
- Знімки (бажано): Element Web того самого випуску з нашим `config.json` у Playwright — сторінка входу, домашня сторінка,
  список кімнат + чат, світла й темна теми OKO, 1920×1080. Артефакт `oko-desktop-screenshots`.
- **Відома проблема (знайшов інтегратор):** за замовчуванням Element вмикає «Тема як у системі», і тоді показує
  **стандартні** теми Element, а не OKO (`ThemeWatcher` бере лише вбудовані теми; налаштування `use_system_theme`
  зберігається лише на пристрої, через `config.json` не вимикається). Дослідити й описати в звіті варіанти:
  (а) без коду — якщо такий спосіб є; (б) інструкція працівнику (Налаштування → Вигляд → вимкнути «як у системі» →
  вибрати OKO); (в) мінімальна правка коду — **лише описати зону, рядки й ризик, не робити** без погодження.

### Е4. Оновлення й інструкція
- Опиши в звіті, як перейти на нову версію Element: змінити `ELEMENT_WEB_TAG` → прогін → перевірка знімків.
- Інструкція для власника (до 1 сторінки): завантажити артефакт, встановити, що робити з попередженням Windows SmartScreen
  про невідомого видавця (бо підпису коду немає), де налаштування теми.
- Канал автооновлень для нашої версії — **не робити**, лише запропонувати варіанти в звіті.

## Межі
- Код Element не змінювати; форк `element-web` не створювати.
- Без Mac, без купівлі сертифіката підпису коду, без секретів.
- Дані: жодних справжніх адрес серверів, паролів, токенів у конфігах.
