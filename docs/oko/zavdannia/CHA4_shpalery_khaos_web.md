## Мета

1. Власник затвердив нові шпалери **«Інтератлетика» — «хаос без підписів»**. Вони **замінюють** шпалери ЧА3
   (46 сюжетів) у світлій темі OKO — і в застосунку для Windows, і в Element Web.
2. Element Web з дизайном OKO вбудовується в програму ОКО (панель чату, завдання ПЧ1 у `Allmytools/prozorro-tracker`).
   Потрібен **готовий вебпакет**, який адміністратор просто розгортає на адресі чату — з темою, шрифтом, шпалерами й
   налаштуваннями, тим самим, що в застосунку для Windows (одне джерело).

## Частина А — шпалери

1. **Перевірка й відтворення.** У workflow: звірити `SHA256SUMS` (архів і два еталони); розпакувати; зібрати за README
   архіву (`NOTAG=1 NOTB=1 BASE_D=310 … desktop 3`, `… BASE_P=215 … phone 4`, `rsvg-convert`) і **попіксельно
   порівняти з еталонами — різниця 0**. Не збігається → збірка падає (це наш захист від підміни файлів). Потрібні пакети
   — з README (Python, pillow, numpy, opencv-python, scipy, librsvg, шрифт Liberation Sans Narrow).
2. **У збірку кладемо еталонні PNG як є** (без перестискання, без зміни розміру):
   `interatletika_khaos_chystyi_3840x2160.png` і `…_phone_1290x2796.png` → `webapp/themes/oko/wallpaper/`.
   Генератор, фото, SVG у збірку не класти.
3. **Як показувати.** Це **не плитка**, а цілісна композиція — не повторювати (`no-repeat`), заповнювати стрічку
   (`background-size: cover`, `background-position: center`), не `fixed`. Широка стрічка → настільна версія; вузька й
   висока (співвідношення сторін вікна < 1, напр. панель чату в ОКО ~480 px) → телефонна. Колір фону стрічки світлої
   теми OKO — **`#EFEAE2`** (замість `#F4F0E9` з ЧА3), щоб краї зображення не відрізнялися.
4. **Темна тема OKO — без шпалер** (однотонний `#101317`): темного варіанта «хаосу» власник ще не затвердив. Старий
   темний SVG з ЧА3 прибрати з використання (файли не видаляти).
5. **Механізм ЧА3 лишається:** маркер у темах OKO, лише стрічка повідомлень, вбудовані теми Element без шпалер,
   збірка падає, якщо після зміни `ELEMENT_WEB_TAG` селектори зникли.
6. **Читабельність:** на знімках перевірити службові рядки стрічки, що лежать прямо на шпалерах (час, «Х приєднався»,
   розділювач дати, «прочитано»). Якщо контраст < 4.5 : 1 — не змінювати картинку, а додати під ці рядки напівпрозору
   підкладку кольором фону (CSS, лише в темі OKO) і описати у звіті.

## Частина Б — вебпакет OKO для панелі чату в ОКО

1. **Одна тема на все:** узяти `oko_element_themes.json` (ПЧ1, шрифт Onest) і шрифти з `deploy/element-web/fonts/` у
   `desktop/config/` як **єдине джерело** теми; застосунок для Windows і вебпакет беруть тему звідси. Звірити з темою ЧА2
   (кольори мають збігатися; розбіжності — у звіт, не вирішувати самому).
2. **Налаштування:** перенести вимкнення функцій з `config.oko.json` ПЧ1 (дзвінки, віджети, реєстрація, скидання
   пароля тощо) у генератор конфігу; сервер за замовчуванням — **`https://m.pro.ua`** (ім'я `m.pro.ua`), і для Windows, і
   для вебу (замість заглушки `matrix.example`).
3. **Новий артефакт `oko-web`** (той самий workflow або окремий `oko-web-build`, Linux): офіційний випуск Element Web
   тегу з `desktop/ELEMENT_WEB_TAG` (перевірити підпис/контрольну суму випуску) + тема, шрифти, шпалери, `<link>` на CSS
   шпалер у `index.html`, `config.json` → архів `oko-web-<тег>.tar.gz` + `SHA256`. Адміністратор лише розпаковує його на
   адресі чату.
4. **Інструкція адміністратору** `docs/oko/ROZHORTANNIA_WEB.md` простими словами: розпакувати, заголовки сервера
   (`Content-Security-Policy: frame-ancestors https://<адреса ОКО>`, без `X-Frame-Options`), HTTPS, Element на піддомені
   того самого домену, що й ОКО; як оновлювати (новий архів → замінити теку); як перевірити (сторінка відкривається, тема
   OKO, шпалери у світлій темі).
5. Знімки (`oko-web-screenshots`, Chromium): вебпакет у вікні 480×900 (як панель у ОКО) і 1440×900, світла й темна тема
   OKO, вбудована тема Element (без шпалер); Windows-застосунок — світла тема з новими шпалерами.
