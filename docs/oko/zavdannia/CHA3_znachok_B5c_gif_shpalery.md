## Мета

Покласти в обидві збірки новий значок OKO **B5c** (око більше + бульбашка), анімацію інсталятора Windows і шпалери стрічки
чату (лише Windows / веб). Код екранів Element не змінювати.

| Що | Де |
|---|---|
| Десктоп: значки, логотип входу, знак домашньої, GIF, шпалери | `Allmytools/oko-chat-android`, гілка `ai/oko-dyzain-desktop`, коміт `5cbe9e54`, тека `branding/oko/desktop/` |
| Android: значок, onboarding, заставка | `Allmytools/prozorro-tracker`, гілка `ai/oko-chat-dyzain`, коміт `2a69f5be`, тека `docs/tz_interface/oko_chat_android/` (слоти Element X — `README.md` там же) |

Файли переносити **як є**, не перемальовувати. `wallpaper/lib.py`, `wallpaper/vig.py` — скрипти дизайнера, у збірку не класти.

## Частина А — Windows (гілка `ai/oko-desktop`, PR №2)

1. **Пакет дизайну.** Перенести в `ai/oko-desktop` зміни `branding/oko/desktop/` з `ai/oko-dyzain-desktop` (`5cbe9e54`)
   — злиттям гілки дизайнера або копіюванням файлів; історію не переписувати.
2. **Значок B5c.** Нові `icons/*`, `login/logo.svg`, `home/oko_znak.svg` мають потрапити в збірку тим самим шляхом, що й зараз.
3. **GIF інсталятора** (🟢). `install-spinner.gif` (320×320) має замінити стандартну анімацію Squirrel (`loadingGif`)
   Element Desktop. Знайти в `apps/desktop` тегу `v1.12.36`, звідки береться GIF (ймовірно `build/install-spinner.gif`), і
   копіювати наш файл туди під час збирання, як значки. Код Element не змінювати.
4. **Шпалери стрічки** (🟡, погоджено інтегратором з умовами нижче).
   - **Колір фону.** У світлій темі OKO фон стрічки `#F4F0E9`, у темній `#101317` — через тему (`theme_oko_light.json`,
     `theme_oko_dark.json`: `timeline-background-color` або відповідний токен Compound). Фон решти інтерфейсу не міняти.
   - **Візерунок.** Окремий файл `oko-wallpaper.css` + `wallpaper_light.svg` / `wallpaper_dark.svg` у `webapp/themes/oko/`,
     підключення одним рядком `<link>` у `index.html` вебпакета **під час збирання** (так само, як ми вже додаємо ресурси в
     `webapp.asar`). Вихідний код Element не правити.
   - **Лише область повідомлень** кімнати (стрічка). Бічна панель, список кімнат, поле введення, налаштування — без змін.
   - **Лише для тем OKO.** Вбудовані теми Element (світла, темна, висококонтрастна) мають лишитися без візерунка.
     Світла тема OKO → `wallpaper_light.svg`, темна → `wallpaper_dark.svg`. Знайти надійний спосіб розрізнити активну тему
     (клас / атрибут, який Element ставить на сторінку). Якщо надійного способу без коду немає — **зупинитися** і
     описати варіанти у звіті («НЕЗАВЕРШЕНО»), нічого не вигадувати.
   - **Захист від оновлень.** Workflow `oko-desktop-build` має **падати**, якщо CSS-селектори, на які спирається
     `oko-wallpaper.css`, зникли з CSS вебпакета нової версії Element. Тоді при заміні `ELEMENT_WEB_TAG` ми одразу побачимо, що
     шпалери треба підправити.
   - Плитка не повинна заважати прокручуванню й продуктивності: `background-attachment` не `fixed`, файл не збільшувати.
5. **Перевірка конфігурації** (`desktop/config/verify.mjs`) — доповнити: у пакеті є GIF, CSS шпалер, обидва SVG, рядок
   `<link>` в `index.html`.
6. **Знімки** (артефакт `oko-desktop-screenshots`): вхід, домашня й тестова кімната у світлій і темній темах OKO **з
   шпалерами**, плюс та сама кімната у вбудованій світлій темі Element (має бути без візерунка).
7. Записати зміни в `OKO_PATCHES.md` з зонами (GIF 🟢, значки 🟢, колір фону 🟡, CSS шпалер 🟡).

## Частина Б — Android (гілка `ai/oko-brand`, PR №1)

1. Оновити пакет `branding/oko/paket_android/` файлами з `prozorro-tracker` `2a69f5be`
   (`docs/tz_interface/oko_chat_android/`): `icon/`, `onboarding/`, `splash/`. `notification/` — без змін.
2. Розкласти по слотах Element X згідно з `README.md` дизайнера: значок застосунку (adaptive: foreground / background /
   monochrome, legacy 48–192), `onboarding_logo` світлий/темний, заставка `oko_splash` світла/темна. Код екранів не
   змінювати.
3. **Шпалер на Android не робимо** (🔴, у Element X немає місця для фону стрічки без зміни коду екрана). Окремо, лише
   дослідження: чи є в Element X поточної версії (тег, від якого зроблено `oko/main`) підтримка фону чату без правки коду
   екрана — так/ні з посиланням на файл; у звіт.
4. Якщо доручення **ЧА1-02** (підпис тестового APK, варіант «а») ще не здане — виконати разом; артефакт
   `oko-test-apks-debugkey`.
5. **Знімки:** значок на робочому столі (світла й темна тема лаунчера, тематичний значок Android 13+), заставка світла й
   темна, екран входу з `onboarding_logo`. Можна з емулятора в CI.
