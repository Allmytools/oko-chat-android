# ДД1 — дизайн OKO для комп'ютера (Element Desktop / Element Web) — завдання дизайн-агенту (26.11.2026)

**Виконавець:** дизайн-агент «ОКО · Дизайн чату». Мітка на початку кожної відповіді: «[ОКО · Дизайн чату]».

## Мета
Комп'ютерна версія OKO має виглядати як та сама родина, що й Android: той самий знак, ті самі кольори й назва «OKO».
Основа — Element Desktop (програма для Windows; усередині — Element Web). Функції не змінюються.

## Головна відмінність від Android
На комп'ютері вигляд задається **файлом налаштувань `config.json` і темою кольорів**, а не кодом. Тому тут ширша
зелена зона: можна змінити шрифт, сторінку входу й домашню сторінку. Будова екранів (розташування, кнопки, меню) —
так само червона зона.

## Що зробити (зелена зона)
1. **Тема кольорів «OKO»** — світла й темна, у форматі власної теми Element Web (`setting_defaults.custom_themes`):
   - блок `colors`: `accent-color`, `primary-color`, `warning-color`, `sidebar-color`, `roomlist-background-color`,
     `roomlist-text-color`, `roomlist-text-secondary-color`, `roomlist-highlights-color`, `roomlist-separator-color`,
     `timeline-background-color`, `timeline-text-color`, `timeline-text-secondary-color`, `timeline-highlights-color`,
     `username-colors` (8 значень), `avatar-background-colors` (8 значень);
   - блок `compound` — перевизначення семантичних токенів Compound. Це **ті самі токени, що в Android**
     (`bgAccentRest` → `--cpd-color-bg-accent-rest` тощо). Значення бери з `brand.json` Android, щоб кольори були однакові;
   - фон і основний текст лишай як у стандартних темах Element (білий / темний): від них залежить контраст;
   - контраст — як у правилах Android (розділ 6.4): текст ≥ 4,5:1, значки й рамки ≥ 3:1. Таблиця — у `PEREVIRKA.md`.
2. **Шрифт** (необов'язково): тема дозволяє свій шрифт. Якщо власник захоче Inter, як в ОКО, — дай файли шрифту з
   ліцензією SIL OFL і блок `fonts`.
3. **Сторінка входу:** фон (`welcome_background_url`, 1920×1080, світлий, без дрібного тексту) і логотип у заголовку
   (`auth_header_logo_url`, SVG, ~200×60). Посилання внизу (`auth_footer_links`) — за переліком власника або без них.
4. **Домашня сторінка** (`home_url`, показується, коли не відкрито жодну кімнату): простий HTML у стилі ОКО — знак OKO,
   2–4 рядки правил чату, посилання на ОКО. Без зовнішніх скриптів, шрифтів і картинок з інтернету — усе локальними файлами.
5. **Назва в текстах:** `brand: "OKO"`.
6. **Значок програми** (на панелі завдань, у треї, в інсталяторі) — той самий знак, що на Android, у варіантах:
   - `icon.png` — 512×512 px, прозорий фон;
   - `icon.ico` — Windows, усередині розміри 16, 24, 32, 48, 64, 128, 256 px. Малі розміри (16–32) — спрощений знак,
     перевір читабельність у треї на світлій і темній панелі Windows;
   - (за потреби) анімація встановлення `install-spinner.gif`, 320×320;
   - значок для Mac **не робимо**, поки власник не скаже, що в команді є Mac.
7. **Значок вкладки браузера** для Element Web: `favicon.ico` (16, 32, 48) і PNG 192×192 і 512×512.

## Чого не робити (червона зона)
Розташування панелей, кнопок, меню; розміри й закруглення; нові екрани чи елементи; зміна текстів інтерфейсу, крім
назви; назва й логотип Element у нашому бренді; шпалери чату.

```
branding/oko/desktop/
  theme_oko_light.json, theme_oko_dark.json   теми у форматі custom_themes
  config_branding.json                        brand, branding, embedded_pages, default_theme
  login/background.jpg, login/logo.svg
  home/home.html (+ локальні файли)
  icons/icon.png, icons/icon.ico, icons/favicon.ico, icons/icon-192.png, icons/icon-512.png
  fonts/ (якщо власник погодить шрифт)
  previews/   макети: вхід, список кімнат + чат, домашня сторінка — світла й темна, 1920×1080
  PEREVIRKA.md   контраст, відповідність кольорів Android, перелік зон
```
